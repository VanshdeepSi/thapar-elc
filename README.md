# Thapar Experiential Learning Centre (ELC) — Official Homepage

> **Thapar Institute of Engineering and Technology (TIET), Patiala, Punjab**  
> Established January 2018 under visionary guidance and academic collaboration with the **University of Waterloo, Canada**.

---

## 🌟 Overview & Design Philosophy

This homepage is designed to present ELC as an **elite, world-class engineering and experiential research centre** (comparable to Waterloo Ideas Clinic, MIT Media Lab, and Stanford d.school).

### Key Features
1. **Academic Industrial Aesthetic**: Rooted in Thapar's heritage crimson (`#881337`), slate obsidian (`#0b0f17`), architectural off-white (`#f8fafc`), and technical brass/amber (`#d97706`).
2. **Subtle Engineering Canvas**: Ultra-quiet, ambient mathematical node-and-coordinate grid running in the background at 60fps with mouse-parallax damping. No flashy cartoon animations.
3. **100% Grounded Content**:
   - **Real Leadership**: Dr. Ravinder Kumar Duvedi (Associate Dean), Dr. Sharad Saxena (Coordinator), Prof. Sanjeev Bedi (NSERC Design Chair, Univ. of Waterloo).
   - **Real Facilities**: 240-student activity space, 3 dedicated Maker Spaces (Mechanical, Electrical, Robotics) open 9:00 AM – 11:00 PM.
   - **Real Breakthroughs**: Thar-EV (150+ students), Autonomous Outdoor Buggy (Military Literature Festival), ThaparSat Calibration Chamber, Jee-1 Ventilator & Robo-Sahayak with PGIMER Chandigarh.
   - **Interactive 5-Semester Curricular Progression Arc**: Computer Science, Chemical, ECE, and Instrumentation modules.
   - **Interactive Technical Project Dossiers**: Modal breakdowns with tooling, mentors, cohort sizes, and field outcomes.

## 🚀 How to Run Locally

### Option 1: Direct Browser Launch
Simply double-click `index.html` in file explorer or open it directly in Google Chrome, Microsoft Edge, or Firefox.

### Option 2: Local HTTP Server (Node.js)
```bash
cd thapar-elc-homepage
npx serve . -l 3000
```
Then visit: `http://localhost:3000`

### Option 3: Python Built-in Server
```bash
cd thapar-elc-homepage
python -m http.server 3000
```
Then visit: `http://localhost:3000`
